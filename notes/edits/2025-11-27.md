# Code Changes - November 27, 2025

## Flow and Source Tag Editing UI Improvements

### Separated Tag Editing from Info Modals
- **Sources Table**: Added separate edit icon next to info icon for tag editing
  - Info icon opens DetailModal (read-only, no tag editing)
  - Edit icon opens TagEditModal directly for tag management
  - Removed tag edit button from DetailModal for sources (`showTagEdit={false}`)

- **Flows Table**: Combined tag and flow property editing into single modal
  - Removed duplicate edit icon (previously had separate tag edit icon)
  - Single edit icon opens EditFlowModal with tabs (Properties and Tags)
  - Tag editing integrated directly into EditFlowModal (no separate modal)

### EditFlowModal Enhancements
- **Tabbed Interface**: Added tabs for "Properties" and "Tags"
- **Integrated Tag Management**: Tag editing now built into modal (no separate TagEditModal)
  - Existing tags displayed with delete buttons
  - Add new tag form with support for string and array values
  - Real-time tag updates with parent refresh
- **Compact Layout**: Made flow properties section more compact
  - Reduced spacing and padding throughout
  - Side-by-side layout for Codec/Container and Bit Rate fields
  - Smaller font sizes for helper text
  - Compact tabs and buttons

### Removed Source ID Filter from Flows Table
- Removed Source ID search field from filter section
- Removed `filterSourceId` state and related filtering logic
- Removed URL parameter handling for `source_id` filter

### Tags Display on Segments Page
- Added tags display section at top of segments page
- Shows tags (year, genre, sport) as chips above flow info
- Light blue background to distinguish from flow information
- Only displays if tags exist and match allowed tags
