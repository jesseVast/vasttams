### 2. Videotools API Integration Fixes

**VideoSource Parameter Fixes:**
- **Issue**: `VideoSource` expects `path` or `stream_url`, not `url`
- **Fix**: Updated `media_processor.py` to use `path` for local files
- **Fix**: Updated `stream_processor.py` to use `stream_url` for streaming URLs
- **Fix**: Fixed `metadata` parameter to always be a dict (not None)

**ChunkOutput API Migration:**
- **Issue**: New `ChunkOutput` API uses `chunk_config` instead of direct parameters
- **Fix**: Updated `folder_ingestor/media_processor.py` to use `process_video_with_chunks_async()` helper function
- **Fix**: Updated to use `ChunkingTransformConfig`, `VideoTransformConfig`, and `AudioTransformConfig`
- **Fix**: Simplified code from ~200 lines to ~80 lines using helper functions

**LiveStreamChunkOutput Compatibility:**
- **Issue**: `LiveStreamChunkOutput` accessing attributes that don't exist in new API
- **Fix**: Added backward compatibility properties:
  - `self.duration = self.chunk_config.segment_duration`
  - `self.format = self.chunk_config.video_config.format`
  - `self.include_timestamps = self.chunk_config.include_timestamps`

## Technical Details

### Videotools Helper Functions Used

**folder_ingestor:**
- `process_video_with_chunks_async()` - Main helper for video chunking
- `ChunkingTransformConfig` - Configuration for chunking behavior
- `VideoTransformConfig` / `AudioTransformConfig` - Codec and format settings

**stream_ingestor:**
- `LiveStreamChunkOutput` - Custom chunk output for live streams
- Uses `chunk_config` API with backward compatibility properties

### Source Reuse Logic

**folder_ingestor:**
- Looks up source by `folder_path` tag (absolute path)
- Double-checks before creating to prevent duplicates
- Reuses existing source if found

**stream_ingestor:**
- Looks up source by `stream_input_source` tag (stream URL)
- Reuses existing source if found
