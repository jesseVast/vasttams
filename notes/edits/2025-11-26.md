# Code Changes - November 26, 2025

## Multiview Segments View Implementation

### New Components
- **MultiviewSegmentsView.tsx**: New component for grid-based multiview segment display
  - Supports HLS playback with shared manifest and time offsets
  - Responsive grid layout (1-4 columns) with vertical scrolling
  - Fetches HLS manifest once and creates blob URL for all players
  - Calculates time offsets for each segment based on timerange

- **ScrollableSegmentsView.tsx**: Extracted scrollable view into separate component
  - Horizontal scrolling segment display
  - Maintains existing autoplay functionality

### UI Improvements
- Added view mode toggle switch (Scrollable/Multiview)
- Changed autoplay button to toggle switch
- Placed autoplay toggle next to view mode switch
- Multiview set as default view mode
- Autoplay disabled by default

### HLS Integration
- Integrated hls.js for HLS-compatible flows (video/mp2t)
- Shared manifest approach with time offsets per segment
- Improved seek handling to avoid playback interruption
- Better error handling and logging for HLS playback

## Server Fixes

### CORS Configuration
- Made CORS settings configurable via config.yaml
- Added CORS configuration loading in Settings class
- Default allows all origins (`["*"]`) for development
- CORS middleware now reads from config instead of hardcoded values

### Blocking Operations Fix
- Fixed blocking database operations in flow delete methods
- Wrapped `execute()` calls in `asyncio.to_thread()` to avoid blocking event loop
- Fixed `delete_flow()` and `_delete_flow_segments()` methods
- UI now remains responsive during delete operations

### Objects Query Fix
- Removed non-existent `summary` column from objects SELECT query
- Summary is a VAST extension, not part of TAMS spec
- Fixed COLUMN_NOT_FOUND errors in Trino queries
- Made summary-related methods more robust with error handling
