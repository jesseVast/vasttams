# TAMS Project Notes

This directory contains organized, date-based notes for the BBC TAMS project.

## 📁 Structure

- **`YYYY-MM-DD.md`** - Daily notes for specific dates
- **`current.md`** - Current status and active work
- **`archive/`** - Archived older notes
- **`edits/`** - Code changes tracking by date
- **`dev-docs/`** - Development documentation and analysis

## 📝 Usage

- **Daily Notes**: Create `YYYY-MM-DD.md` for each day's work
- **Current Status**: Keep `current.md` updated with latest status
- **Archives**: Move completed work to `archive/` folder
- **Edits**: Track code changes in `edits/YYYY-MM-DD.md`

## 🔄 Migration from Old System

- **NOTES.md** → Split into date-based files
- **EDITS.md** → Split into date-based edit files

- **Latest Status**: See `current.md`
