## 🔧 **Technical Details**

### **Content-Type Serialization Fix**
The issue was that Pydantic's alias handling requires using `model_validate()` with a dict when the field has an alias:
```python
# ❌ Doesn't work with aliases
HttpRequest(content_type="video/mp2t")  

# ✅ Works correctly
HttpRequest.model_validate({"content-type": "video/mp2t"})
```

### **Credential Validation Pattern**
```python
# Only use backend if credentials are valid
access_key = storage_backend.get('access_key') if storage_backend else None
secret_key = storage_backend.get('secret_key') if storage_backend else None
has_valid_credentials = (
    access_key and secret_key and 
    isinstance(access_key, str) and isinstance(secret_key, str) and
    access_key.strip() and secret_key.strip()
)
```
