### Key Features

1. **Hybrid Threshold System**:
   - Quantity: >50 segments → immediate async
   - Time: ≤50 segments but >30 seconds → switch to async

2. **Non-Blocking Processing**:
   - Background tasks process deletions in batches
   - Event loop remains responsive

3. **Client Support**:
   - Handles 202 responses automatically
   - Provides deletion request domain object
   - Easy status polling

4. **TAMS 8.0 Compliant**:
   - Follows TAMS spec for delete-requests
   - Returns proper 202 Accepted with Location header
   - Status tracking: created → started → done/error

### Configuration
- Quantity threshold: 50 segments (in router)
- Time threshold: 30 seconds (in router)
- Batch size: 50 segments (in deletion service)
